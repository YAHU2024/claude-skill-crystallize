# 终极思路沉淀智能体技能 (Global Crystallize Thought Process)

当你（Claude）发现解决了一个复杂的代码问题，或者用户在任意项目中主动输入了 `/crystallize` 时，请触发本技能。

## 执行步骤：

1. **精准分类判定**：
   从以下高频场景中选择最契合的 **1-2个标签**：
   `[Bug修复]`, `[性能优化]`, `[新功能实现]`, `[架构设计]`, `[重构]`, `[环境配置]`, `[依赖问题]`, `[部署问题]`, `[工程化]`, `[Prompt优化]`, `[AI工作流]`

2. **多维提取与格式化**：
   严格按照以下 Markdown `<details>` 模板组织内容。务必提取出技术栈关键词、复用价值，以及**真实的失败尝试**。

3. **目录与文件准备 (全局环境关键步骤)**：
   由于你运行在各种不同的项目中，请务必先在终端隐式执行以下命令确保目录存在：
   `mkdir -p docs`

4. **持久化追加**：
   将生成的 Markdown 文本**追加（Append）**到当前项目根目录的 `docs/THOUGHTS.md` 文件末尾（用两行空行隔开，**绝对不可覆盖历史记录**）。

5. **VS Code 联动**：
   写入完成后，在终端执行 `code -r docs/THOUGHTS.md` 唤起用户的编辑器。
